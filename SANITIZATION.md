# Repository Sanitization Notes

This GitHub-ready copy was prepared from the project source with public sharing in mind.

Excluded:
- Python virtual environments and caches
- Generated static files
- Runtime logs and backups
- Uploaded media
- `.orig` backup files
- Local/private workspace folders

Replaced with examples:
- Production domain names
- Deployment usernames and server paths
- Company-specific email addresses
- Company-specific VAT/CR/address test data
- Deployment database connection examples

The application/project identifiers such as `takharuj_backend` and `takharuj_*` local-storage keys were retained because they are code identifiers, not credentials.
