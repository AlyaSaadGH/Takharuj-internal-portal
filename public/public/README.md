# Fawateer Platform Frontend

المشروع مقسم إلى صفحات مستقلة مع ملفات CSS و JavaScript مشتركة.

## التشغيل
1. فك الضغط.
2. افتح مجلد المشروع في VS Code.
3. افتح `index.html` باستخدام Live Server.

## الصفحات
- `index.html` لوحة التحكم
- `create-invoice.html` إنشاء فاتورة
- `invoices.html` الفواتير
- `clients.html` العملاء
- `packages.html` الباقات
- `reports.html` التقارير
- `team.html` الفريق
- `settings.html` الإعدادات

اللغة والدارك مود محفوظة في LocalStorage وتعمل على جميع الصفحات.
